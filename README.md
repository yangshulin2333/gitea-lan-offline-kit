# Gitea 局域网离线部署工具包

**简体中文（默认）** | [English](README.en.md)

面向小团队的 Windows x64 局域网 Git 工具包：Gitea 服务端、Git 与 TortoiseGit 客户端安装材料，以及中文部署和协作教程。

> **预发布版本，尚未完成干净电脑离线部署验收。** 当前测试环境已完成常见协作、重启恢复及备份演练；请先在独立测试机按清单验收，再用于正式项目。

## 下载与开始

从本仓库 **Releases** 下载完整离线包或成员客户端包。Git 源码仓库只保存脚本和文档，大型安装程序放在 Release 附件中。

1. 全部解压，先阅读 `完整中文操作手册.html`。
2. 安装 Git；服务器上以管理员身份运行 `工具/01-部署新服务器.ps1`。
3. 在本机网页初始化数据库并亲自创建管理员。
4. 运行 `工具/02-开放局域网.ps1`，再配置成员、组织和仓库。
5. 按验收清单检查重启、协作、保护规则和备份恢复。

**不要在已有 Gitea 实例上运行新部署脚本。** 本包不含预设密码、数据库、仓库和真实用户信息。

## 功能

- SQLite3，无需另装数据库、Docker、Node 或 Python。
- LocalService 服务身份、延迟自动启动、异常退出重启。
- 仅本机初始化，完成后开放选定局域网地址。
- 停服备份、逐文件 SHA-256 校验。
- 克隆、分支、提交、推送、评审、合并、撤销与文本冲突教程。
- 中文默认文档；完整英文部署指南附中文界面和提示词对照。当前脚本交互提示为中文。

## 兼容性与边界

目标是 Windows 10/11 Intel/AMD x64；已实际使用的环境为 Windows 11 x64，Windows 10 待验收。ARM64、32位和旧版 Windows 不在支持范围内。需要本机管理员权限、健康本地 NTFS 磁盘和局域网。

未完成跨机恢复和全新离线安装实测；保护规则拦截验证曾跳过。出现过 OAuth 首次认证失败、重试成功，原因仍待排查。仅提供受控局域网 HTTP 方案，不是公网托管方案。
